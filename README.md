# Mundo Singular

Protótipo inicial de tecnologia educacional inclusiva.

## MVP atual
- Experiência responsiva para criança/tablet/celular
- Módulo Comunicação e Linguagem
- Atividade 01: **Quero água**
- Apoio visual após tentativa diferente da resposta-alvo
- Registro local da resposta independente ou com apoio durante a sessão
- Preferências sensoriais iniciais

## Princípios
O Mundo Singular é um recurso educacional. Não realiza diagnóstico clínico, não classifica a criança por percentual de autismo e não substitui professor, família ou profissionais especializados.

## Próximas etapas
1. Painel do educador
2. Perfil pedagógico e preferências sensoriais
3. Cinco atividades de comunicação funcional
4. Persistência segura de dados
5. Piloto supervisionado em ambiente educacional
6. Revisão técnica/pedagógica e LGPD antes de uso com dados reais de crianças

## Execução
O protótipo é estático. Abra `index.html` ou publique com GitHub Pages.

> Status: protótipo para demonstração e validação; não utilizar com dados pessoais reais de crianças nesta versão.
